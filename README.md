# LLM Lab: Build a (Tiny) LLM from Scratch

Welcome to the **LLM Lab** on YLabs! In this lab, you will build a complete, generative Transformer model from first principles using pure **Python and NumPy**.

## 🚀 Lab Overview
This lab takes you from raw text to numbers, through scaled dot-product attention, residual connections, and layer normalization, culminating in building and training your own **TinyGPT** with emergent transformer capabilities.

### Sprints & Milestones
- **Sprint 1 · Foundations: From Text to Numbers** (Vectors, Cosine Similarity, BPE Tokenizer, Embeddings)
- **Sprint 2 · Predicting the Next Word** (Linear Projections, Logits, Stable Softmax, Temperature)
- **Sprint 3 · The Attention Mechanism** (Scaled Dot-Product, Causal Masking, Multi-Head Attention)
- **Sprint 4 · The Transformer Architecture** (LayerNorm, Residuals, GELU, Feed-Forward Network, Transformer Blocks)
- **Sprint 5 · Generation & Sampling** (Greedy, Top-K, Top-P Nucleus Sampling, Autoregressive Generation)
- **Sprint 6 · Capstone Project: TinyGPT** (Synthetic Corpus Training & Emergent Behavior Verification)
